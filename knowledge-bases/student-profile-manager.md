# 学生档案管理器（Student Profile Manager）

管理多个学生的独立学习档案，让 AI 家教具备跨会话记忆。通常与 primary-tutor-template（教学方法）配合：本 skill 管「教谁、学到哪」，模板管「怎么教」。

## 档案存放

- 目录：`~/.claude/student-profiles/`（Windows 即 `C:\Users\<用户名>\.claude\student-profiles\`）
- 每个学生一个 Markdown 文件，以学生名字或昵称命名（如 `小明.md`）
- 目录不存在时自动创建；首次没有任何档案时引导新建

## 一、开课流程（辅导会话开始时必做）

1. **读名单**：列出档案目录下所有文件名（即学生名单）
2. **选人**：用点选方式让学生/家长选「我是谁」，并提供「🆕 新学生」选项；多个孩子同时在场时，先选「今天学谁」，一次只教一个，防止进度互相污染
3. **老学生**：读取档案，开场回顾（欢迎回来 + 上次进度 + 检查上次口头作业），再继续未完成内容
4. **新学生**：创建新档案，询问并记录：姓名/昵称、年级学期、学习偏好、目标，然后按 primary-tutor-template 的流程开课

## 二、档案统一格式

```markdown
# 学生档案：<姓名>
- 年级/学期：如"四年级上（2026 秋）"
- 地区/教材：如"深圳 · 数学北师大版，语文部编版"（决定用哪个知识库）
- 学习偏好：听讲/做题/边讲边练/听故事
- 目标：兴趣/掌握/考试提分
- 使用设备：如"iPad，不会打字，全点选交互"

## 语文进度
- 已完成：<课文名/单元> ✅
- 下一步：<下一篇/待巩固点>
- 背诵打卡：<已背篇目清单>

## 数学进度
- 口算段位：青铜/白银/黄金/王者
- 已学单元：<单元名>
- 下一步：<单元/待巩固点>

## 错题本（按知识点记，不按题号）
- ⚠️ <知识点>：<错因诊断>（已教方法：<方法>，状态：待巩固/已攻克）

## 口头作业
- <作业内容>（布置日期）
```

## 三、更新规则

1. **下课或达成里程碑时**更新档案（不是每题都写，避免刷屏）
2. 错题本按知识点维护：同知识点再错→更新状态与错因；连对 2 次→标「已攻克 ✅」
3. 口头作业：检查后记录结果（完成/未完成），再布置新作业
4. 口算段位按对应知识库的段位表升级，升级时在档案记录日期
5. 档案未记录的信息不乱补，不确定时先问家长
6. 学年升级（每学年开学）：提醒家长更新"年级/学期"，难度与知识库随之切换

## 四、隐私规则（强制）

1. 档案含孩子姓名与学习数据，**仅本地保存**
2. 禁止将档案内容上传到任何公开仓库、云盘或发送给外部服务
3. 如需在公开示例中展示格式，一律使用虚构姓名（如"小明"）
