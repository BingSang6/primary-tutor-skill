# 深圳小学试卷模板规格

## 〇、总原则
1. 对齐深圳真实考试：孩子做咱们的卷 = 提前适应学校考试
2. **所有试卷必须输出为可打印的 docx**（配合 document-skills:docx 的 exam 场景规则排版），参考答案单独成文件
3. 深圳命题趋势：**情境化命题**（如"小记者""逛博物馆"串联全卷）、新课标素养立意——高年级卷尽量设计情境主线
4. 各区（福田/南山/罗湖/宝安等）自主命题有差异，以下为通用基准

# 一、语文试卷规格（部编版）

## 卷面结构：三大模块（深圳标准）

| 模块 | 分值占比 | 内容 |
|------|---------|------|
| 一、积累与运用 | 35~40 分 | 看拼音写词语、读音选择、形近字/组词、补充词语、选词填空、句子练习（修辞/改写）、按课文内容填空、日积月累/古诗 |
| 二、阅读理解 | 30~35 分 | 课内阅读 1 篇 + **课外阅读 1~2 篇**（深圳重视课外阅读，至少 1 篇） |
| 三、习作 | 25~30 分 | 与课本习作训练点一致（四年级常为 25~30 分，题目二选一更常见） |

## 时长与满分
- 单元卷：60 分钟，100 分
- 期中/期末卷：90 分钟，100 分

## 卷面细节（打印相关）
- 答题卡：小学阶段**直接在试卷上作答**（无答题卡），需预留书写空间
- 作文：**方格稿纸**（习作要求 ≥300 字时给 ≥400 格；四年级 25 分习作建议 20×15 格）
- 卷首：区/学校名 + 考试名称 + 年级学科 + "（满分 100 分，时间 X 分钟）" + 姓名/班级/学号栏
- 正式卷用**密封线**（左侧竖排"密……封……线……内……不……要……答……题"）；日常练习用横排信息栏即可

# 二、数学试卷规格（深圳·北师大版）

## 卷面结构（北师大版单元卷常见六题型）

| 题型 | 分值 | 说明 |
|------|------|------|
| 一、口算/直接写得数 | 10~15 | 热身送分题，20 题左右 |
| 二、填空 | 15~20 | 按本册知识点（数位、规律、数对等） |
| 三、选择 | 5~10 | 常含"下列说法正确的是" |
| 四、竖式计算/脱式计算（含简算） | 20~25 | **北师大四上必考运算律简算**；预留竖式书写空间 |
| 五、操作题（画图） | 5~10 | 画角/画垂线/数对标位置（需留空白作图区+方格） |
| 六、解决问题 | 20~25 | 情境化应用题（购物/行程/统计），每题答句"

## 出题范围
- **严格按北师大版单元顺序**（见 math-grade4-bsdz-shenzhen），不出人教版才有、北师大未学的内容
- 深圳数学卷趋势（参考南山期末卷热议）：**综合、情境化、阅读量大**——高年级适当加"长题干情境题"，但提前学阶段以基础为主

## 时长与满分
- 单元卷：60 分钟（低年级 40~50），100 分
- 期中/期末：90 分钟（低年级 60~70），100 分

# 三、打印规格（交给打印机前必查）

## 纸张
| 卷型 | 纸张 | 版式 |
|------|------|------|
| 正式单元/期中/期末卷 | 8 开（约 A3，260×370mm） | 双面，正式卷可双栏 |
| 日常练习卷 | A4 | 单面/双面，单栏 |
| 参考答案 | A4 | 单独文件，家长保管 |

## 排版硬性要求（生成 docx 时执行）
1. 黑白灰配色（复印友好），宋体正文 10.5pt、黑体大题标题 11pt
2. 大题"一、二、三…"，小题"1. 2. 3."，子题"(1)(2)(3)"
3. 题干与作答区不跨页拆开（keepNext）
4. 选择题选项用无边框表格对齐，不用空格
5. 竖式计算题每题留 2~3 行空白；解决问题留 3~5 行；画图题留方格区
6. 页脚页码（只显当前页码，不显"共 X 页"）
7. 密封线（仅正式卷）：左侧预留装订边距 2.2cm

## 打印建议（给家长）
- 家用 A4 打印机：用"日常练习卷"版式；8 开卷可缩印为 A4（缩放 71%）
- 打印店：直接给 docx 或 PDF，说明"8 开双面"
- 建议双面打印节省纸张，与学校卷一致

# 四、生成流程

1. 问清：哪个学科、哪个单元/期中/期末、正式卷还是日常卷
2. 从对应知识库取范围（语文=年级课文库+chinese-primary-curriculum；数学=北师大/人教对应库）
3. 按上述结构配分值 → 出题（不超纲）→ 生成 docx（docx skill exam 场景规则）→ postcheck 验证
4. 参考答案单独文件，答案与试卷题号一一对应
5. 交付时告知打印方式（A4/8 开、单双面）
