# 如何录入一个新的年级知识库

本仓库已内置：
- **数学 1~6 年级全学段**（math-primary-renjiao.md）——无需录入
- **语文 1~6 课程框架**（chinese-primary-curriculum.md）：必背古诗文原文、小古文、习作序列——无需录入

**唯一需要家长自己录入的**：各年级语文的**现代课文原文 + 生字表**（版权原因，请勿公开分享含课文原文的库）。

## 录入三步法

### 第 1 步：提供原料（任选）
- 拍照：课本目录页、写字表/识字表页、需要学的课文页
- 语音念、打字、粘贴均可
- 原料给 AI（如 Claude Code + 本模板），说：「帮我录入 X 年级语文知识库」

### 第 2 步：按此模板生成 SKILL.md

```markdown
---
name: chinese-gradeX-renjiao-20XX
description: 20XX秋人教部编X年级X册语文知识库，仅本地自用。
---

# 全局执行规则
1. 检索优先：仅使用本库内容作答，未收录直接告知，不编造
2. 听写规则：单字逐个报，等反馈后给读音/部首/组词
3. 出题不超本册范围

# 全书目录
（单元 → 课文，含*略读课文标记）

# 写字表（按单元）
（每单元一行，顿号分隔）

# 识字表

# 课文（逐篇）
## N 课文标题
（原文全文）
### 课后习题
### 日积月累/资料袋（如有）
```

### 第 3 步：安装
```bash
mkdir -p ~/.claude/skills/chinese-gradeX-renjiao
# 把 SKILL.md 放进去；ZCode 用户在 ~/.agents/skills/ 建 junction
```
并在该学生的档案中标注使用哪个知识库。

## 注意事项
1. 含课文原文的库**仅个人本地使用**，禁止上传公开仓库
2. 数学其他版本教材（北师大/苏教等）可参照 math 库的格式录入对应知识点
3. 英语等其他学科同理：家长供原料，AI 按模板加工
