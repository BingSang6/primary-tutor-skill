# 第一单元 认识更大的数

1. **计数单位与数位顺序表**：个十百千…亿；每相邻两个计数单位进率 10；从右起每四位一级（个级/万级/亿级）
2. **亿以内数的读写**：读法——先读万级再读个级，万级末尾加"万"；每级末尾 0 不读，中间连续几个 0 只读一个零。写法——从高位写起，空位用 0 占位
3. **数的大小比较**：位数多的大；位数相同从最高位比起
4. **改写与近似数**：整万数改写成"万"（=）；四舍五入到万位/亿位求近似数（≈）：看省略部分的最高位，≥5 进 1，<5 舍去
5. **自然数**：0,1,2,…；最小是 0，没有最大；表示物体个数
6. **十进制计数法**；认识数位顺序表中"数位"与"计数单位"的区别

## 北师大特色：用"数线（直线）"标数、感受大数（人口普查、国土数据情境）
## ⚠️ 易错：中间 0 的读法（40050000 读四千零五万）；"改写"与"近似数"符号混用（= 与 ≈）

# 第二单元 线与角

1. **线段、射线、直线**：线段两个端点可度量；射线一个端点无限延伸；直线无端点无限延伸；过一点可画无数条直线，过两点只能画一条
2. **相交与垂直**：两条直线相交成直角时互相垂直，交点叫垂足；点到直线的距离——垂直线段最短
3. **平行**：同一平面内不相交的两条直线互相平行
4. **角的表示与度量**：用符号 ∠ 表示角；量角器"中心对顶点、0 线对一边、另一边读刻度、分清内外圈"
5. **角的分类**：锐角<90°；直角=90°；钝角（大于 90° 小于 180°）；平角=180°；周角=360°。1 平角=2 直角；1 周角=4 直角
6. **画角**：射线 → 对量角器 → 点刻度 → 连线 → 标符号与度数

## ⚠️ 易错：量角器内外圈读反；钝角范围表述不完整；垂线忘了标直角符号

# 第三单元 乘法

1. **三位数乘两位数笔算**：个位乘完，再用十位乘（积末位与十位对齐），两次积相加
2. **估计**：把因数看成整十整百数估算（198×21≈200×20=4000）；解决购物情境
3. **神奇的计算工具**：认识计算器（M+、MR 等按键使用）
4. **有趣的算式**：探索规律（如 1×1、11×11、111×111 的积的规律）
5. **大数的乘法应用**：路程=速度×时间；总价=单价×数量（北师大在情境中反复出现）

## ⚠️ 易错：十位相乘积的对位；中间有 0 的乘法漏乘；估算写"="不写"≈"

# 第四单元 运算律（北师大四上重点！人教四下才学）

1. **加法交换律**：a+b=b+a
2. **加法结合律**：(a+b)+c=a+(b+c)
3. **乘法交换律**：a×b=b×a
4. **乘法结合律**：(a×b)×c=a×(b×c)
5. **乘法分配律**：(a+b)×c=a×c+b×c —— 简算核心，必考！
6. **简便运算应用**：
   - 凑整：25×4=100、125×8=1000、5×2=10
   - 例：25×32×125 = 25×4×8×125 = 100×1000 = 100000
   - 例：102×45 = (100+2)×45 = 4500+90 = 4590
   - 例：99×38 = (100-1)×38 = 3800-38 = 3762

## ⚠️ 易错：分配律与结合律混淆（把 (a×b)×c 也拆开）；减法/除法没有分配律的错用；符号漏括号

# 第五单元 方向与位置（人教四下才学）

1. **去图书馆（描述路线）**：用"方向+距离"描述行走路线：先向__方向走__米，再向__方向走__米
2. **确定位置（数对）**：用"数对（列,行）"表示位置——**先数列（横），再数行（竖）**；（3,4）表示第 3 列第 4 行
3. 方向口诀：上北下南左西右东；东北/东南/西北/西南（"北偏东"等说法初中才严格化）

## ⚠️ 易错：数对先列后行写反；（2,3）与（3,2）是不同位置

---

# 第六单元 除法

1. **买文具（除数整十）**：如 80÷20、150÷50 的口算与竖式
2. **三位数除以两位数笔算**：
   - 先看前两位，前两位不够除看前三位
   - 试商："四舍"试商偏大调小、"五入"试商偏小调大
   - 口诀："四舍商易大，五入商易小；余数比除数，大了就得调"
   - 除到哪一位，商就写在那一位上；每次余数必须小于除数
3. **商不变的规律**：被除数和除数同乘或同除以相同的数（0 除外），商不变 —— 简算工具（如 1200÷25 = (1200×4)÷(25×4) = 4800÷100 = 48）
4. **商是几位数的判断**：前两位 ≥ 除数 → 商两位数；否则商一位数
5. **路程问题**：时间=路程÷速度

## ⚠️ 易错：商的位置写错；余数 ≥ 除数未调商；商不变规律中"0 除外"

# 第七单元 生活中的负数（人教六下才学！北师大四上就接触）

1. **温度**：零上温度与零下温度；0℃ 是分界；-5℃ 比 0℃ 低，比 -10℃ 高
2. **正负数**：表示**相反意义**的量——零上为正、零下为负；收入为正、支出为负
3. **0 的特殊性**：0 既不是正数也不是负数
4. **比较大小**：正数 > 0 > 负数；负数比较：数字越大的负数反而越小（-8 < -3）

## 教学注意：四上只要求"初步认识"（温度、收支情境），不要求负数运算！
## ⚠️ 易错：-8 与 -3 比大小（孩子易答 -8 大）

# 第八单元 可能性

1. **不确定性**：可能、一定、不可能（太阳一定从东边升起；明天下雨是"可能"）
2. **可能性的大小**：数量多的可能性大，数量少的可能性小
3. 摸球、转盘等实验情境判断

## ⚠️ 易错："可能"与"一定"混淆；可能性大小与数量关系判断反了
