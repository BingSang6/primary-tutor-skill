# 人教版小学数学 1~6 年级知识库

## 使用规则
1. 检索优先：先匹配本知识库，未收录则回复「当前知识库未收录该内容」
2. 出题严格限制在孩子所学年级的知识范围内，不超前（如三年级不出方程、四年级不出分数乘除）
3. 搭配 primary-tutor-template 的教学方法与分学段适配规则

# 一年级（上/下）

## 上册：数一数 / 比一比 / 1~5 的认识和加减法 / 认识图形（一）/ 6~10 的认识和加减法 / 11~20 各数的认识 / 认识钟表 / 20 以内的进位加法
## 下册：20 以内的退位减法 / 认识图形（二）/ 100 以内数的认识 / 认识人民币 / 100 以内的加法和减法（一）/ 找规律

- 数的认识：数数、顺序、比大小（>、<、=）
- 加减法含义：合起来用加、去掉用减；看图列式
- 钟表：认识整时、半时（分针指 12 是整时，指 6 是半时）
- 人民币：1 元 = 10 角，1 角 = 10 分；简单换算与购物
- ⚠️ 易错：左右方位混淆；"比多比少"看错谁多；半时分针指 6 不是指 30

# 二年级（上/下）

## 上册：长度单位 / 100 以内的加法和减法（二）/ 角的初步认识 / 表内乘法（一）/ 观察物体（一）/ 表内乘法（二）
## 下册：数据收集整理 / 表内除法（一）/ 图形的运动（一）/ 表内除法（二）/ 混合运算 / 有余数的除法 / 万以内数的认识 / 克和千克 / 数学广角（推理）

- 长度单位：米、厘米；1 米 = 100 厘米；测量从 0 刻度开始
- 乘法初步：乘法是相同加数连加的简便算法；口诀 1×1 到 9×9 熟背
- 除法初步：平均分用除法；用口诀求商
- 有余数的除法：余数必须小于除数（核心考点）
- 混合运算顺序：先乘除后加减；有括号先算括号
- 质量：1 千克 = 1000 克；掂一掂建立感觉
- ⚠️ 易错：余数 ≥ 除数；单位"米/厘米""克/千克"选错；乘法口诀 7×8、6×9 串记

# 三年级（上/下）

## 上册：时分秒 / 万以内的加法和减法（一）/ 测量 / 万以内的加法和减法（二）/ 倍的认识 / 多位数乘一位数 / 长方形和正方形 / 分数的初步认识 / 数学广角（集合）
## 下册：位置与方向 / 除数是一位数的除法 / 复式统计表 / 两位数乘两位数 / 面积 / 年月日 / 小数的初步认识 / 数学广角（搭配）

- 时分秒：1 时 = 60 分，1 分 = 60 秒；经过时间 = 结束 - 开始
- 测量：毫米、分米、千米；吨；1 吨 = 1000 千克
- 倍的认识：几倍就是几个几
- 多位数乘一位数：中间有 0 的乘法；估算
- 周长：长方形周长 =(长+宽)×2；正方形周长 = 边长×4
- 分数初步：把整体平均分成几份，一份就是几分之一；分子分母含义；同分母分数加减
- 面积：面积含义；1 平方厘米/分米/米；长方形面积 = 长×宽；正方形面积 = 边长×边长
- 年月日：大月 31 天（1,3,5,7,8,10,12），小月 30 天，平年 2 月 28 天、闰年 29 天；平年 365 天
- 小数初步：以元角米为单位认识一位小数；简单比较大小
- ⚠️ 易错：周长和面积概念混淆；进率（面积单位进率是 100）；平闰年判断

# 四年级（上/下）

## 上册：大数的认识 / 公顷和平方千米 / 角的度量 / 三位数乘两位数 / 平行四边形和梯形 / 除数是两位数的除法 / 条形统计图 / 数学广角（优化）
## 下册：四则运算 / 观察物体（二）/ 运算定律 / 小数的意义和性质 / 三角形 / 小数的加法和减法 / 图形的运动（二）/ 平均数与条形统计图 / 数学广角（鸡兔同笼）

## 上册要点
- 大数：亿以内读写（每级末尾 0 不读，中间连续 0 只读一个零）；四舍五入求近似数
- 面积单位：1 公顷 = 10000 平方米；1 平方千米 = 100 公顷
- 角：线段/射线/直线；锐角<90°<钝角<180°=平角；周角 360°；量角器"中心对顶点，0 线对一边"
- 乘法：积的变化规律；单价×数量=总价；速度×时间=路程
- 平行四边形与梯形：两组/一组对边平行；高与底；长方形正方形是特殊的平行四边形
- 除法：试商"四舍商易大，五入商易小"；余数<除数；商不变规律
- 优化：烙饼问题（3 张饼 3 次）；能同时做的事同时做

## 下册要点
- 四则运算：运算顺序；0 不能作除数；租船问题
- 运算定律：加法交换/结合律；乘法交换/结合/分配律（a×c + b×c =(a+b)×c，简便计算核心）
- 小数意义：分母是 10、100、1000 的分数；小数点移动引起大小变化；近似数
- 三角形：任意两边之和大于第三边；内角和 180°；按角/按边分类；高的画法
- 小数加减：小数点对齐再加减
- 平均数：总数量 ÷ 总份数 = 平均数
- 鸡兔同笼：假设法（假设全是鸡 → 兔数 =（实际脚数 - 2×头数）÷2）
- ⚠️ 易错：乘法分配律用成结合律；小数点对齐（不是末位对齐）；三角形两边和定理

# 五年级（上/下）

## 上册：小数乘法 / 位置 / 小数除法 / 可能性 / 简易方程 / 多边形的面积 / 数学广角（植树问题）
## 下册：观察物体（三）/ 因数与倍数 / 长方体和正方体 / 分数的意义和性质 / 图形的运动（三）/ 分数的加法和减法 / 折线统计图 / 数学广角（找次品）

- 小数乘除：按整数算再点小数点；除数变整数（商不变）；循环小数；进一法/去尾法取近似
- 简易方程：用字母表示数；等式性质解方程；列方程解应用题
- 多边形面积：平行四边形 = 底×高；三角形 = 底×高÷2；梯形 =(上底+下底)×高÷2（转化思想：推导全靠剪拼）
- 植树问题：两端都栽 +1；一端栽不加不减；两端不栽 -1；封闭图形 = 周长÷间隔
- 因数与倍数：2/3/5 的倍数特征；质数合数；奇偶性
- 长方体正方体：棱长和；表面积；体积 V=Sh；1 立方米 = 1000 立方分米；容积
- 分数意义：单位"1"；约分通分；真分数假分数；分数与除法关系 a/b = a÷b
- 折线统计图：看变化趋势
- 找次品：3 的幂次分组策略（3 个称 1 次找出）
- ⚠️ 易错：方程忘写"解"；三角形/梯形面积忘除以 2；植树问题加减 1

# 六年级（上/下）

## 上册：分数乘法 / 位置与方向 / 分数除法 / 比 / 圆 / 百分数（一）/ 数学广角（数与形）
## 下册：负数 / 百分数（二）/ 圆柱与圆锥 / 比例 / 数学广角（鸽巢问题）及总复习

- 分数乘除：乘法意义（求一个数的几分之几）；除法 = 乘倒数
- 比：比的基本性质；化简比；按比例分配
- 圆：圆周率 π；C = πd = 2πr；S = πr²；环形面积 = π(R²-r²)
- 百分数：百分数与分数小数互化；百分率（出勤率、发芽率）；折扣、纳税、利息
- 数与形：正方形数 1+3+5+…+n = n² 等规律
- 负数：表示相反意义的量；-5 < -2 < 0 < 2（数轴理解）
- 圆柱圆锥：圆柱 V = πr²h；圆锥 V = 1/3 × 底面积 × 高（等底等高圆锥是圆柱的 1/3）
- 比例：比例的基本性质（内项积 = 外项积）；正比例 y/x = k，反比例 xy = k
- 鸽巢原理：n+1 个物体放进 n 个抽屉，至少有一个抽屉 ≥2 个
- ⚠️ 易错：圆的面积与周长公式混用；单位"1"找错；圆锥体积忘乘 1/3；正反比例判断

## 常见单位进率汇总
- 长度：1 米 = 10 分米 = 100 厘米；1 千米 = 1000 米
- 质量：1 吨 = 1000 千克；1 千克 = 1000 克
- 面积：1 平方米 = 100 平方分米；1 公顷 = 10000 平方米；1 平方千米 = 100 公顷
- 体积：1 立方分米 = 1000 立方厘米；1 升 = 1000 毫升
- 时间：1 时 = 60 分；1 分 = 60 秒
