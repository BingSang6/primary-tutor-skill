# Primary Tutor Skill（小学家庭辅导技能模板）

一个为 [Claude Code](https://code.claude.com/docs/zh-CN/skills) / ZCode 等 AI 编程助手设计的 **Skill 模板**：把 AI 变成一位有耐心、会闯关、会发贴纸奖励的小学家教。

专为**还不会打字的小学生**设计 —— 孩子全程只需用手指**点选答案**，在 iPad 上即可完成学习。

> ⚠️ 本仓库只包含**教学方法**，不含任何教材原文（无版权风险）。请搭配您孩子自己的课本内容使用。

---

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 🔘 **零打字交互** | 所有题目以点选方式出题，孩子用 iPad 点一点就能答题 |
| 🔀 **防蒙设计** | 正确答案位置随机打乱，测出真实水平 |
| 🎮 **闯关制** | 每个小环节是一关，通关发 ASCII "贴纸"奖励 |
| 📈 **进度地图** | ✅/⬜ 清单让孩子直观看到自己的积累 |
| ✍️ **单字听写** | 一次只报一个字，写完反馈后再给读音、部首、组词 |
| 🎯 **考点标注** | 必背 ⭐ / 易错 ⚠️ / 考点 🎯，直击考试 |
| 📄 **试卷生成** | 可生成 A4 打印友好的 Word 试卷 + 单独的参考答案 |
| 🚫 **不编造** | 知识库没有的内容如实告知，绝不瞎编课文 |

## 🚀 安装使用

### 1. 安装 Skill

```bash
# Claude Code 用户
mkdir -p ~/.claude/skills
git clone https://github.com/BingSang6/primary-tutor-skill.git ~/.claude/skills/primary-tutor-template
```

ZCode 用户请克隆到 `~/.agents/skills/`（或建软链指向 `~/.claude/skills/`）。

### 2. 准备课本知识库（教什么）

本模板只管"怎么教"。您需要再准备一个知识库 skill（含生字表、课文、古诗词等），方法：

- 参考官方 [Skills 文档](https://code.claude.com/docs/zh-CN/skills) 写一个 `SKILL.md`，把孩子课本的**目录、生字表、必背内容、日积月累**整理进去
- 或直接在对话中把课本内容发给 AI

> 📌 教材原文仅供个人学习使用，请勿将包含教材内容的知识库公开发布。

### 3. 开始学习

对孩子（或家长）这样说即可：

```
辅导孩子学习四年级语文第一课
给我第一单元生字听写
出一份第二单元测试卷
```

## 🧩 五步教学法

```
① 认字/认词 → ② 读内容 → ③ 讲重点 → ④ 背默写 → ⑤ 练习巩固
```

每讲一小段，立刻出 3~4 道点选题检验 —— 边讲边练，不等全部讲完才考。

## 📁 目录结构

```
primary-tutor-skill/
├── SKILL.md                                  # 教学方法 skill（1~6 年级，需搭配下述知识库与档案管理）
├── knowledge-bases/
│   ├── math-primary-renjiao.md               # 数学 1~6 年级全学段知识库
│   ├── chinese-primary-curriculum.md         # 语文 1~6 年级课程框架知识库（含必背古诗文原文）
│   ├── student-profile-manager.md            # 学生档案管理 skill（多学生/进度/错题本，档案仅本地）
└── README.md                                 # 本文件
```

两个知识库均为课程标准层内容（知识点、公式、公版古诗文），不含现代教材原文，可放心公开。安装时把 `knowledge-bases/` 下的文件也放到 skills 目录即可搭配使用。
